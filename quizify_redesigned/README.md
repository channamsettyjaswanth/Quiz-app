# Quizify - Flutter UI Design Lab

A modern dark-theme quiz application built with Flutter and Material 3.

## Features
- Four quiz categories: Flutter, Java, Python, General Knowledge
- Five multiple-choice questions per category
- One answer per question with instant feedback
- Previous and Next navigation
- Progress bar and live score
- Final score, percentage, correct/incorrect count
- Play Again and Back to Home actions
- Responsive scrolling layouts

## Run
1. Install Flutter SDK and Android Studio or VS Code.
2. Extract this ZIP.
3. Open the `quizify_redesigned` folder.
4. Run:
   ```bash
   flutter pub get
   flutter run
   ```

No external packages are required.
